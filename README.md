# Arquitectura de Computadoras

Material teórico-práctico de Arquitectura de Computadoras (Facultad de Informática, UNLP).

## Estructura

- `teoria/`: diapositivas de las clases teóricas.
- `practica/`: prácticas y resoluciones.
- `parciales/`: parciales de años anteriores.
- `final/`: material para preparar el final.

## Temas

- Arquitectura y organización: modelo de von Neumann, buses, pipeline
- CPU: conjuntos de instrucciones, CISC y RISC (MIPS, ARM), interrupciones
- Entrada/salida: puertas serie y paralelo, polling, interrupciones y DMA
- Memoria: jerarquía, caché y memoria virtual
- Paralelismo: procesadores superescalares, taxonomía de Flynn, multiprocesadores

---

Las resoluciones son propias y pueden tener errores. El material de cátedra (diapositivas, enunciados y parciales) pertenece a sus docentes y está incluido solo como referencia de estudio.
